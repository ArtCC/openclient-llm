Resumen

OpenClient no envía analíticas, telemetría ni informes de fallos al desarrollador. La aplicación funciona principalmente en tu dispositivo. Los datos solo salen para proveedores configurados y ascendentes, Apple Speech cuando corresponda, el uso del panel de Votice, iCloud o compras voluntarias procesadas por StoreKit.

Servicios del desarrollador

OpenClient no usa un backend del desarrollador para conversaciones, analíticas, telemetría, seguimiento de uso ni informes de fallos. Configurar, abrir o usar el panel de comentarios puede contactar con el servicio Votice operado por el desarrollador, como se explica más abajo.

Almacenamiento local e iCloud

Salvo las transmisiones descritas a continuación, los datos gestionados por la aplicación se almacenan en tu dispositivo o en tu cuenta personal de iCloud. El desarrollador no tiene acceso a esos datos almacenados. En concreto:

  • Contenido — se guardan localmente las conversaciones; los archivos binarios de adjuntos por separado, incluidos documentos e imágenes generadas; el perfil JSON; la memoria JSON, incluida la creada por modelos; las plantillas de prompts personalizadas; y los metadatos de eliminación.
  • Sincronización con iCloud — este contenido solo se sincroniza si iCloud está disponible y el ajuste de sincronización de la aplicación está activo. Desactivarlo detiene futuras sincronizaciones de la aplicación, pero no elimina automáticamente los archivos que ya estén en iCloud.
  • Ajustes — permanecen en el dispositivo.
  • Claves de API y URL del servidor — almacenadas exclusivamente en el Llavero del dispositivo mediante el framework Security de iOS/macOS. Nunca se transmiten al desarrollador.
  • Índice de Spotlight — los títulos de las conversaciones y fragmentos de mensajes se indexan localmente en Spotlight para permitir búsquedas en el dispositivo. Estos datos no abandonan tu dispositivo.
  • App Group — los widgets guardan una instantánea limitada de hasta seis conversaciones recientes (título, modelo, vista previa del último mensaje y fecha). La Extensión de compartir y Atajos preparan temporalmente texto, URL, imágenes o PDF hasta que la aplicación los consume o borra. Estos datos permanecen en el dispositivo y solo se comparten entre la aplicación principal y sus extensiones.

Comunicación con el servidor

La aplicación envía solicitudes a la URL que proporcionas: una instancia de Ollama, un proxy de LiteLLM u otro backend compatible con OpenAI. Según su configuración, ese servidor puede reenviar contenido a proveedores ascendentes de modelos o búsquedas, que pueden registrarlo, conservarlo o tratarlo según sus propias políticas.

  • Mensajes y contexto; en chats no privados, el contexto efectivo puede incluir perfil y memoria
  • Imágenes y documentos adjuntos a los mensajes (Vision)
  • Datos de audio para transcripción de voz: según el ajuste de transcripción seleccionado, el audio se envía al servidor configurado mediante /v1/audio/transcriptions o se procesa con el framework Speech de Apple. Apple Speech puede procesarlo según el comportamiento y los ajustes de Apple, sin garantía de que el proceso se realice en el dispositivo.
  • Texto para síntesis de voz (Text-to-Speech mediante /v1/audio/speech)
  • Prompts para generación de imágenes; las imágenes generadas llegan en respuestas de chat completions compatibles
  • Consultas de búsqueda web, que tu servidor LiteLLM reenvía al proveedor de búsqueda que hayas configurado en el servidor (p. ej., Brave, Tavily, DuckDuckGo). La aplicación nunca contacta directamente con los proveedores de búsqueda.
  • Entradas y salidas de llamadas a herramientas cuando el modo agente está activo

El desarrollador no recibe esta comunicación salvo que opere el servidor o proveedor que configures.

Contenido compartido e importado

El contenido recibido a través de la Extensión de compartir, el esquema de URL personalizado (openclient://), arrastrar y soltar, o los Atajos de Apple se procesa íntegramente en tu dispositivo y puede enviarse al servidor configurado y sus proveedores ascendentes cuando lo uses en una solicitud. El desarrollador no lo recibe de otro modo.

Dependencias de terceros y analíticas

La aplicación incluye VoticeSDK y ConfettiSwiftUI como dependencias en tiempo de ejecución. No integra redes publicitarias, frameworks de seguimiento ni SDKs de analítica. SwiftLint se usa como herramienta de análisis de código durante la compilación y no forma parte de la aplicación distribuida.

VoticeSDK ofrece el panel opcional de comentarios en Ajustes. Puedes enviar comentarios de forma anónima, sin cuenta ni nombre obligatorio. Configurar, abrir o usar el panel puede enviar un identificador de dispositivo aleatorio y persistente, además de datos técnicos como plataforma, idioma y versión/build, para gestionar sugerencias, comentarios y votos y evitar duplicados. El identificador no contiene directamente nombre, correo, credenciales de API ni conversaciones. El texto, las imágenes y el apodo opcionales solo se envían si decides proporcionarlos. Los comentarios pueden ser visibles para otros usuarios.

Código abierto y auditable

OpenClient es completamente de código abierto bajo la GNU Affero General Public License v3.0. Puedes inspeccionar, auditar y verificar cada línea de código en el repositorio de GitHub. Esta transparencia permite revisar el tratamiento de datos de la aplicación.

Privacidad de menores

La aplicación no solicita conscientemente información personal de menores de 13 años. No envíes datos personales de un menor mediante chats, adjuntos, voz, búsquedas o comentarios salvo autorización legal.
