Résumé

OpenClient n'envoie ni analyses, ni télémétrie, ni rapports de crash au développeur. L'application fonctionne principalement sur votre appareil. Des données n'en sortent que pour les fournisseurs configurés et en amont, Apple Speech le cas échéant, Votice, iCloud ou les achats volontaires traités par StoreKit.

Services du développeur

OpenClient n'utilise pas de backend du développeur pour les conversations, analyses, télémétrie, suivi d'utilisation ou rapports de crash. Configurer, ouvrir ou utiliser le tableau de retours peut contacter le service Votice exploité par le développeur, comme indiqué ci-dessous.

Stockage local et iCloud

À l'exception des transmissions décrites ci-dessous, les données gérées par l'application sont stockées sur votre appareil ou dans votre compte iCloud personnel. Le développeur n'accède pas à ces données stockées. En particulier :

  • Contenu — sont stockés localement : conversations ; fichiers binaires séparés des pièces jointes, dont des documents et des images générées ; profil JSON ; mémoire JSON, dont celle créée par les modèles ; modèles d'invites personnalisés ; et métadonnées de suppression.
  • Synchronisation iCloud — ce contenu n'est synchronisé que si iCloud est disponible et si le réglage iCloud de l'application est activé. Le désactiver arrête les futures synchronisations de l'application, sans supprimer automatiquement les fichiers déjà présents dans iCloud.
  • Réglages — restent sur l'appareil.
  • Clés API et URL du serveur — stockées exclusivement dans le Trousseau de l'appareil via le framework Security d'iOS/macOS. Jamais transmises au développeur.
  • Index Spotlight — les titres des conversations et les extraits de messages sont indexés localement dans Spotlight pour permettre la recherche sur l'appareil. Ces données ne quittent pas votre appareil.
  • App Group — les widgets conservent un aperçu limité de six conversations récentes au plus (titre, modèle, aperçu du dernier message et date). L'extension de partage et Raccourcis placent temporairement du texte, des URL, images ou PDF jusqu'à leur utilisation ou suppression par l'application. Ces données restent sur l'appareil et ne sont partagées qu'entre l'application principale et ses extensions.

Communication avec le serveur

L'application envoie les requêtes à l'URL fournie : instance Ollama, proxy LiteLLM ou autre backend compatible OpenAI. Selon sa configuration, ce serveur peut transmettre le contenu à des fournisseurs de modèles ou de recherche en amont, qui peuvent le journaliser, le conserver ou le traiter selon leurs propres politiques.

  • Messages et contexte ; pour les chats non privés, le contexte effectif peut inclure profil et mémoire
  • Images et documents joints aux messages (Vision)
  • Données audio pour la transcription vocale : selon le réglage de transcription sélectionné, l'audio est envoyé à votre serveur configuré via /v1/audio/transcriptions ou traité avec le framework Speech d'Apple. Apple Speech peut traiter l'audio selon le comportement et les réglages d'Apple, sans garantie d'un traitement sur l'appareil.
  • Texte pour la synthèse vocale (Text-to-Speech via /v1/audio/speech)
  • Invites pour la génération d'images ; les images générées arrivent dans des réponses de chat completions compatibles
  • Requêtes de recherche web, que votre serveur LiteLLM transmet au fournisseur de recherche que vous avez configuré côté serveur (ex. : Brave, Tavily, DuckDuckGo). L'application ne contacte jamais directement les fournisseurs de recherche.
  • Entrées et sorties des appels d'outils lorsque le mode agent est actif

Le développeur ne reçoit pas cette communication, sauf s'il exploite le serveur ou fournisseur configuré.

Contenu partagé et importé

Le contenu reçu via l'extension de partage, le schéma d'URL personnalisé (openclient://), le glisser-déposer ou les Raccourcis Apple est traité entièrement sur votre appareil et envoyé uniquement à votre serveur configuré et à ses fournisseurs en amont lorsque vous l'utilisez dans une requête. Le développeur ne le reçoit pas autrement.

Dépendances tierces et analyses

L'application inclut VoticeSDK et ConfettiSwiftUI comme dépendances d'exécution. Elle n'intègre aucun réseau publicitaire, framework de suivi ni SDK d'analyse. SwiftLint est un outil d'analyse du code utilisé lors de la compilation et ne fait pas partie de l'application distribuée.

VoticeSDK fournit le tableau de retours facultatif dans Réglages. Un retour peut être envoyé anonymement, sans compte ni nom obligatoire. Configurer, ouvrir ou utiliser le tableau peut envoyer un identifiant d'appareil aléatoire persistant et des données techniques comme la plateforme, la langue et la version/build, afin de gérer suggestions, commentaires et votes et d'éviter les doublons. L'identifiant ne contient pas directement votre nom, e-mail, identifiants API ou conversations. Texte, images et pseudonyme facultatifs ne sont envoyés que si vous les fournissez. Les retours et commentaires peuvent être visibles par d'autres utilisateurs.

Open source et vérifiable

OpenClient est entièrement open source sous la GNU Affero General Public License v3.0. Vous pouvez inspecter, auditer et vérifier chaque ligne de code dans le dépôt GitHub. Cette transparence vous permet d'examiner le traitement des données par l'application.

Confidentialité des enfants

L'application ne sollicite pas sciemment les informations personnelles d'enfants de moins de 13 ans. Ne transmettez pas celles d'un enfant par chats, pièces jointes, voix, recherches ou retours sans autorisation légale.
