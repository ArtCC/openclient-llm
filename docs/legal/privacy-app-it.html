Riepilogo

OpenClient non invia analisi, telemetria o report di crash allo sviluppatore. L'app funziona principalmente sul dispositivo. I dati ne escono solo per provider configurati e a monte, Apple Speech quando applicabile, uso di Votice, iCloud o acquisti volontari elaborati da Apple tramite StoreKit.

Servizi dello sviluppatore

OpenClient non usa un backend dello sviluppatore per conversazioni, analisi, telemetria, tracciamento o report di crash. La configurazione, apertura o uso della bacheca di feedback può contattare il servizio Votice gestito dallo sviluppatore, come descritto sotto.

Archiviazione locale e iCloud

Ad eccezione delle trasmissioni descritte di seguito, i dati gestiti dall'app vengono archiviati sul tuo dispositivo o nel tuo account iCloud personale. Lo sviluppatore non accede a tali dati archiviati. Nello specifico:

  • Contenuti — sono archiviati localmente conversazioni; file binari separati degli allegati, inclusi documenti e immagini generate; profilo JSON; memoria JSON, inclusa quella creata dai modelli; modelli di prompt personalizzati; e metadati di eliminazione o tombstone.
  • Sincronizzazione iCloud — questi contenuti si sincronizzano solo se iCloud è disponibile e l'impostazione iCloud dell'app è attiva. Disattivarla ferma le future sincronizzazioni dell'app, ma non rimuove automaticamente i file già presenti in iCloud.
  • Impostazioni — restano sul dispositivo.
  • Chiavi API e URL del server — archiviate esclusivamente nel Portachiavi del dispositivo tramite il framework Security di iOS/macOS. Non vengono mai trasmesse allo sviluppatore.
  • Indice Spotlight — i titoli delle conversazioni e gli estratti dei messaggi vengono indicizzati localmente in Spotlight per consentire la ricerca sul dispositivo. Questi dati non lasciano il tuo dispositivo.
  • App Group — i widget conservano un'istantanea limitata di un massimo di sei conversazioni recenti (titolo, modello, anteprima dell'ultimo messaggio e data). Estensione Condivisione e Comandi rapidi depositano temporaneamente testo, URL, immagini o PDF finché l'app non li usa o elimina. Questi dati restano sul dispositivo e sono condivisi solo tra l'app principale e le sue estensioni.

Comunicazione con il server

L'app invia richieste all'URL fornito: un'istanza Ollama, un proxy LiteLLM o un altro backend compatibile con OpenAI. In base alla configurazione, il server può inoltrare contenuti a provider di modelli o ricerca a monte, che possono registrarli, conservarli o elaborarli secondo le proprie informative.

  • Messaggi e contesto; per le chat non private, il contesto effettivo può includere profilo e memoria
  • Immagini e documenti allegati ai messaggi (Vision)
  • Dati audio per la trascrizione vocale: a seconda dell'impostazione di trascrizione selezionata, l'audio viene inviato al server configurato tramite /v1/audio/transcriptions oppure elaborato con il framework Speech di Apple. Apple Speech può elaborarlo secondo comportamento e impostazioni Apple, senza garanzia che l'elaborazione avvenga sul dispositivo.
  • Testo per la sintesi vocale (Text-to-Speech tramite /v1/audio/speech)
  • Prompt per la generazione di immagini; le immagini generate arrivano in risposte chat completion compatibili
  • Query di ricerca web, che il tuo server LiteLLM invia al provider di ricerca che hai configurato lato server (es.: Brave, Tavily, DuckDuckGo). L'app non contatta mai direttamente i provider di ricerca.
  • Input e output delle chiamate agli strumenti quando la modalità agente è attiva

Lo sviluppatore non riceve questa comunicazione, salvo che gestisca il server o provider configurato.

Contenuto condiviso e importato

Il contenuto ricevuto tramite l'estensione Condivisione, lo schema URL personalizzato (openclient://), il trascinamento o i Comandi rapidi Apple viene elaborato interamente sul tuo dispositivo e può essere inviato al server configurato e ai suoi provider a monte quando lo usi in una richiesta. Lo sviluppatore non lo riceve altrimenti.

Dipendenze di terze parti e analisi

L'app include VoticeSDK e ConfettiSwiftUI come dipendenze di runtime. Non integra reti pubblicitarie, framework di tracciamento né SDK di analisi. SwiftLint è usato come strumento di analisi del codice durante la compilazione e non fa parte dell'app distribuita.

VoticeSDK fornisce la bacheca facoltativa di feedback. Puoi inviare feedback anonimo senza account o nome obbligatorio. Configurare, aprire o usare la bacheca può inviare un identificatore casuale persistente del dispositivo e dati tecnici come piattaforma, lingua e versione/build, per gestire suggerimenti, commenti e voti ed evitare duplicati. L'identificatore non contiene direttamente nome, email, credenziali API o conversazioni. Testo, immagini e nickname facoltativi sono inviati solo se li fornisci. Feedback e commenti possono essere visibili ad altri utenti.

Open source e verificabile

OpenClient è completamente open source con GNU Affero General Public License v3.0. Puoi ispezionare, controllare e verificare ogni riga di codice nel repository GitHub. Questa trasparenza ti consente di esaminare il modo in cui l'app gestisce i dati.

Privacy dei minori

L'app non richiede consapevolmente informazioni personali a minori di 13 anni. Non inviare dati personali di un minore tramite chat, allegati, voce, ricerche o feedback senza autorizzazione legale.
