FEATURES

Everything you need to work with your models

🤖

Your AI Server

Connect to Ollama, LiteLLM, or an OpenAI-compatible server and use the models and features it exposes.

🔒

Privacy First

No OpenClient-hosted chat backend. Requests go to your configured server and any upstream providers it uses; API keys stay securely in Keychain.

💬

Real-time Streaming

Stream responses from compatible chat models token by token using Server-Sent Events.

🖼️

Image Generation

Generate images from text prompts using compatible image models exposed by your server.

🎙️

Voice & Audio

Speech-to-text dictation and text-to-speech playback for hands-free interaction.

📎

Vision & Documents

Attach images and PDFs for compatible multimodal models to analyze, summarize, or answer questions about.

🤖

Agent Mode

Let supported models call enabled tools, use their results, and chain actions to complete complex tasks.

🔌

MCP Tools

Discover and use tools from MCP servers configured on your LiteLLM backend.

🧠

Persistent Memory

Memory that persists across conversations. Add your own notes or let the model build it automatically during chat.

GET STARTED

Up and running in two steps

  1. Run Ollama, deploy a LiteLLM proxy, or use a compatible server
  2. Download OpenClient, open Settings, and enter your server URL
